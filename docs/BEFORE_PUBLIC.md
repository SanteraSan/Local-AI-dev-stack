# Перед открытием репозитория

Репозиторий приватный. Когда он пойдёт в портфолио, пройти этот список до переключения видимости на Public. Пункты дополняются по мере появления новых файлов.

## Секреты

- [ ] `.env` нет в истории: `git log --all --full-history -- .env` пусто.
- [ ] В истории нет ключей и токенов: прогнать `gitleaks detect` или `trufflehog git file://.` по всей истории, а не только по текущему коду.
- [ ] В `.env.example` только имена переменных и заглушки.
- [ ] Если секрет когда-либо попадал в коммит — сначала отозвать и перевыпустить его, потом чистить историю (`git filter-repo`). Удаление файла в новом коммите не помогает.

## Описание машины и сети

- [ ] `README.md`, раздел «Железо»: модель видеокарты, процессор, объём памяти, версия Ollama. Решить, оставлять ли. Для портфолио конкретика полезна, но это описание личной машины.
- [ ] `README.md`, раздел «Порты»: список портов TaskFlow. Решить, нужен ли он публично.
- [ ] `docs/DECISIONS.md`: замеры видеопамяти, детали рабочего стола (GNOME на NVIDIA, выключенное ускорение Chrome). Можно обобщить до «ограничение 16 ГБ видеопамяти».
- [ ] Абсолютные пути вида `/home/santera/...` и имя пользователя — заменить на `~` или переменные.

## Конфиги клиентов (появятся в фазе 4)

- [ ] `clients/*`: Cursor, Continue, Roo Code, OpenCode — нет реальных ключей и токенов, только ссылки на переменные окружения.
- [ ] Нет имён внутренних проектов и путей к ним, если они не публичные.

## Память devmem (фаза 3)

- [ ] В репозитории нет экспортов памяти (`devmem export`), дампов Postgres и бэкапов. Они в `.gitignore`, но проверить.
- [ ] Тестовые данные и фикстуры не содержат реальных записей из рабочих проектов.

## Бенчмарк (фаза 6)

- [ ] `bench/tasks/*`: задачи не содержат кода из закрытых или коммерческих проектов.
- [ ] `bench/results/*.jsonl`: нет фрагментов приватного кода в промптах и ответах.

## Упоминания

- [ ] Ссылки на локальный план `~/.cursor/plans/...` — заменить описанием или убрать.
- [ ] Упоминания работодателей и коммерческих проектов — только то, что уже есть в публичном резюме.

## Оформление для портфолио

- [ ] README начинается с того, что это и зачем, схема архитектуры, как поднять.
- [ ] Лицензия.
- [ ] Скриншоты или короткая запись работы: Open WebUI, Roo Code с памятью.
